## v0.50.3 — Validasi saat muat (KONTRAK §Z.0)

Kerjakan:

   parameter per operator (REF §YAML) · `reference_ids` keluarga tidak kosong; keluarga & kondisi (bila ada): tanpa duplikat,
   semua resolve ke `kb_sources.active` · `validation_only` ditolak bila applicability memuat `production` atau `apk_static`.
   Kondisi tanpa `reference_ids` sah (§Y.3.3a: wajib di metadata keluarga).

3. `tests/fixtures/rules/broken/*.yaml` — tiap berkas melanggar **tepat satu** hal, minimal satu per kode di tabel REF §YAML
   kecuali `status_not_allowed`/`kb_incomplete`/`manifest_mismatch` (v0.50.4/v0.90.2); `schema_invalid` minimal 3 berkas:
   field wajib hilang, `any_of`, `unknown_handling` di profil.
4. Test: 5 YAML asli lolos (termasuk 9 kondisi tanpa `reference_ids`); tiap berkas rusak → `RuleLoadError` dengan `code` dan `path`
   yang diharapkan (tabel nama berkas → kode di test).
