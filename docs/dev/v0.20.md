## v0.20.4 — Gerbang allowlist + privilege detector (KONTRAK)
Butuh: v0.20.3 · Env: lokal atau cloud (test pakai mock) · Kelas: **kontrak**

Kontrak: backend hanya kirim operation ID + parameter; ID di luar 8 tidak dapat dieksekusi; string
perintah ADB hanya di `adb_commands.py`; tanpa `shell=True`; privilege hanya dibaca. (REF §OPS)

Kerjakan:
1. `agent/src/device/adb_commands.py`: `DEVICE_LIST = ["devices", "-l"]`, `VERSION = ["version"]`,
   `PRIVILEGE_PROBE = ["shell", "id"]`; dict `OPERATION_ARGS: dict[str, list[str]] = {}` (belum ada pemetaan).
2. `agent/src/acquisition/command_allowlist.py`: `ALLOWED_OPERATIONS: frozenset[str]` = 8 ID REF §OPS;
   `resolve_operation(operation, parameters) -> list[str]`: tidak di allowlist → `OperationNotAllowedError`;
   di allowlist tapi tidak di `OPERATION_ARGS` → `OperationNotMappedError`; tiap penolakan di-audit (ID, alasan, kelas galat).
3. `agent/src/models.py`: `AcquisitionJob` Pydantic `extra="forbid"`: `type` (`"job"`), `session_id`,
   `operation`, `case_id`, `device_id`, `parameters: dict[str, str]`.
4. `agent/src/device/adb_controller.py`: `run_adb(args: list[str], serial: str | None) -> AdbResult`
   (`subprocess.run([adb_path, *(-s serial), *args], shell=False, capture_output=True, timeout=60)`,
   kembalikan bytes stdout/stderr + returncode). ⛔ Tidak menyusun string perintah.
5. `agent/src/device/privilege_detector.py`: jalankan `PRIVILEGE_PROBE`; `uid=0` → `root_detected`,
   selain itu `non_root`, galat → `unknown` (REF §ENUM `PrivilegeState`). ⛔ Tidak pernah mengubah privilege.
6. `agent/tests/unit/test_command_allowlist.py`: jumlah ID = 8; ID sembarang → `OperationNotAllowedError`;
   ID sah belum dipetakan → `OperationNotMappedError`; dua tipe berbeda; job ber-field ekstra → `ValidationError`;
   tiap penolakan menulis 1 baris audit; privilege detector dengan mock `uid=0`/`uid=2000`.

Jangan: mendaftarkan deteksi perangkat sebagai ID operasi. Memetakan ID apa pun (itu v0.30.3).
File: berkas langkah 1–6
Cek:
- `check.sh agent` → OK
- `grep -rnE "shell=True|os\.system|getprop|dumpsys|pm list" agent/src --include=*.py | grep -v adb_commands.py` → kosong
- `grep -nE "root\"|disable-verity|remount|\bsu\b" agent/src/device/privilege_detector.py` → kosong
Uji gagal:
- `cd agent && PY -c "from src.acquisition.command_allowlist import resolve_operation as r; r('adb shell pm uninstall x', {})"` → `OperationNotAllowedError`
- `PY -c "from src.models import AcquisitionJob as J; J(type='job', session_id='s', operation='collect_package_inventory', case_id='c', device_id='d', parameters={}, raw_command='rm -rf /')"` → `ValidationError`
Commit: `feat(agent): enforce allowlisted operation ids and read-only privilege detection [v0.20.4]`
Ref: §V, §B prinsip 6, §U.2, §AD
