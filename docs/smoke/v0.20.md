## Uji gagal

- State machine: `AgentStateMachine().transition_to("disconnected")` dari `starting` → `AgentError: illegal transition starting -> disconnected`.
- `adb emu kill` (v0.20.6) → perangkat `disconnected`, baris tetap.
- Backend mati >30 s (v0.20.5) → agen tersambung ulang otomatis; audit `ws_reconnected`.
- **Dasbor langsung:** agen dimatikan saat dasbor terbuka → `AgentStatus` berubah dari terhubung menjadi terputus tanpa refresh (dikonfirmasi pemeriksa melihat layar, 2026-10-02 00:01).
- Catatan: setelah agen mati, `GET /api/agents` masih `connected: true` sampai 30 detik berlalu (definisi kartu `v0.20.2`); dasbor memakai event langsung sehingga berubah seketika.
