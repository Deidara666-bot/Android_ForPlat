- unggah kedua untuk sesi/sequence/part sama → 409, berkas lama utuh; nama berkas klien `../../evil.txt` tidak berpengaruh (`v0.30.5`);
- AVD mati → dua baris `evidence` `failed` dengan alasan `serial is not a ready device` (`v0.30.6`);
- ID operasi belum dipetakan → 422 "belum dipetakan"; 401/422 sebelum handler diaudit (`v0.30.4`, `v0.30.6`).
